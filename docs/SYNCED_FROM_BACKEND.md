# Copia sincronizada — no editar

Todo lo que hay en esta carpeta (excepto este archivo) es una copia de `docs/` del repo **backend**, que es la fuente de verdad.
Los cambios se hacen en el backend y llegan aquí en un PR automático (rama `sync/backend`, etiqueta `sync`).
Un check de CI rechaza los PRs que editen estos archivos desde otra rama (SPEC REP-01).
